# System Architecture Reference

## Architectural Layers
1. **Data Model Layer (`models/`):** Contains immutable domain entities and dataclass validation schemas.
2. **Quantitative Engine Layer (`engine/`):** Contains high-precision mathematical models for options pricing, stochastic processes, and risk analytics.
3. **Compliance Surveillance Layer (`compliance/`):** Real-time audit logs and regulatory rule compliance monitors.
4. **Service & API Layer (`services/`, `api/`):** Handles REST controllers, WebSocket streaming, and ORM persistence.
5. **User Interface Layer (`ui/`):** Visual widgets and executive PDF/HTML report generators.
6. **Automated Test Suite (`tests/`):** 5+ comprehensive unittest modules covering end-to-end functionality.
